LUMI 学生端前端调试包
======================

适用系统：Windows 10 / Windows 11

一、最快启动方式
1. 解压整个 ZIP 文件，不要直接在压缩包中运行。
2. 确认电脑已安装 Node.js 22 或更高版本。
   下载地址：https://nodejs.org/
3. 双击“一键启动调试.bat”。
4. 第一次运行会自动安装项目依赖，需要保持网络连接。
5. 安装完成后会自动打开：http://localhost:3000/

二、停止服务
关闭“一键启动调试.bat”打开的命令窗口，或在窗口中按 Ctrl+C。

三、手动启动方式
在当前目录打开 PowerShell 或命令提示符，依次执行：

  npm ci
  npm run dev

四、常用检查命令

  npm run lint
  npm test
  npm run build

五、包内内容
- app、components、public：学生端页面、组件与静态资源
- tests：项目回归测试
- package.json、package-lock.json：依赖与命令配置
- 其他配置文件：构建、样式及本地调试配置

说明：本调试包不包含 node_modules、构建缓存、Git 历史和本机临时文件，
因此体积较小；首次启动会通过 npm ci 自动安装完全一致的依赖版本。
