# Lumi 演示手册

## 推荐现场路径（约 6–8 分钟）

1. 使用预填账号登录，选择“小学生”。
2. 在冒险地图展示签到、课程切换和当前学习节点。
3. 进入当前课程，演示单词发音、记忆题、跟读评分与情景对话。
4. 完成课程，展示星星奖励和下一节点解锁。
5. 在“作业与复习”推进一项作业、复习一道错题，返回后星星和待办数同步变化。
6. 在“AI 英语伙伴”选择一个快捷话题，再输入一句自由问题。
7. 在“我的学习”展示书架、统计和设置；最后可重置演示数据。

## 电脑和手机的区别

| 项目 | 电脑浏览器 | Android / iOS 真机 |
| --- | --- | --- |
| 页面内容与本地进度 | 相同 | 相同 |
| 展示面积 | 保留手机画框，适合投屏 | 全屏显示，适合近距离体验 |
| 操作方式 | 鼠标、键盘 | 触控、系统软键盘 |
| 录音 | Web 演示不作为主路径 | Expo 原生录音，是真机语音主路径 |
| 发音 | 浏览器 Web Speech | 系统 Expo Speech |
| 后端地址 | 默认 `127.0.0.1:8000` | 自动尝试 Metro 所在电脑 IP，或使用环境变量配置 |

手机端已使用动态视口和 Android `resize` 键盘模式，输入时页面会让出软键盘空间。不同品牌手机的系统状态栏、字体渲染和 TTS 音色仍会略有差异。

## 现场准备

```powershell
cd app
npm run check
npm run doctor
```

若要演示真实转写或云端 AI，再启动后端：

```powershell
cd server
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

真机无法访问后端时，在 `app/.env` 设置：

```text
EXPO_PUBLIC_API_BASE_URL=http://电脑局域网IP:8000
```

## 异常预案

- 云端 AI、语音评分不可用：应用自动给出标注为“本地演示”的回复或评分，主流程不会中断。
- 语音转文字不可用：直接键入或选择快捷回答继续演示。
- 演示数据与讲稿不一致：进入“我的学习 → 设置 → 重置演示数据”。
- 现场网络不稳定：优先使用电脑浏览器投屏；手机只演示触控和原生录音入口。
