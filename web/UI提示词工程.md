# LUMI 幼儿园 / 小学生端 UI 提示词工程

## 1. 当前界面提取结论

当前项目已经形成稳定的信息架构：登录 → 身份选择 → 学生首页，并使用紫色作为品牌主色、白色卡片承载内容、底部五栏导航组织学生功能。页面逻辑清楚，适合继续扩展。

需要优化的部分：原界面偏通用工具型，儿童品牌记忆点较弱；卡片、图标和反馈样式比较克制；幼儿园及小学低年级需要更大的点击区域、更短的文案、更明显的语音入口和即时奖励。优化应“可爱但不杂乱”，避免玩具化、过度卡通化和高饱和色堆叠。

## 2. 设计模型的角色提示词

```text
你是一名资深儿童教育产品设计师、交互设计师和前端设计系统专家。你正在设计 LUMI 儿童英语智能学习平台的学生端，主要用户为幼儿园大班至小学六年级学生，辅助用户为家长与教师。

你的设计目标是：降低儿童操作难度，鼓励开口说英语，让任务、进度和奖励一眼可懂；整体可爱、温暖、可信，但不能像幼儿玩具，也不能使用复杂的成人数据后台风格。

所有页面必须遵守同一套颜色、字体、圆角、间距、图标、吉祥物和状态反馈规范。优先使用短句、图形、颜色和声音提示表达含义。每个页面只能有一个最明显的主操作。不要创建教师端、家长端或管理后台页面。
```

## 3. 全局视觉提示词

```text
设计一套面向幼儿园和小学生的移动端英语学习产品 UI，品牌名 LUMI，吉祥物为友善的紫色小鹿 Lumi。

视觉关键词：soft playful、pastel、rounded、friendly、safe、encouraging、clean、educational、gentle depth。

主色使用柔和紫 #6257E8，深紫 #312B83；辅助色使用天空蓝 #75C8F8、薄荷绿 #43C9B7、阳光黄 #FFD861、珊瑚粉 #FF8296；页面背景 #F7F8FC；正文 #1F2942；次要文字 #7C869E。颜色用于功能识别和奖励反馈，不要大面积同时出现五种高饱和色。

卡片圆角 18–26px，按钮圆角 14–16px，主要按钮高度至少 50px，儿童可点击区域至少 48×48px。使用轻柔阴影、低对比描边和适量留白。标题圆润有力量，正文清楚易读；中文优先，英文仅作为学习氛围辅助。

加入少量星星、云朵、气泡和小鹿吉祥物，装饰不得遮挡内容。动画只使用轻微漂浮、按钮按压和任务完成庆祝；支持 prefers-reduced-motion。
```

## 4. 信息架构约束提示词

```text
学生端固定保留以下信息架构：
1. 登录页；
2. 身份选择页，只允许学生身份进入，教师与家长入口保留但标记暂未开放；
3. 学生首页；
4. 学习；
5. AI 英语伙伴；
6. 作业；
7. 我的成长。

底部导航固定为：首页、学习、AI伙伴、作业、我的。AI伙伴可以作为视觉中心按钮突出，但不能破坏五栏结构。

当前实现阶段制作登录页、身份选择页、学生首页、学习、AI伙伴、作业和我的成长；教师端与家长端只保留入口，不生成业务页面。
```

## 5. 当前核心页面的复刻提示词

### 登录页

```text
生成 LUMI 学生端登录页，画布尺寸 390×844，浅灰蓝背景。顶部展示 LUMI 品牌名、短句“和小鹿一起，开心学英语”和紫色小鹿吉祥物。使用少量星星、气泡装饰。

表单包含学习账号、登录密码、显示密码按钮。表单上方用气泡提示“请家长或老师帮助小朋友登录哦”。主按钮文案“出发学习”，宽度占内容区全部，高度不小于 50px。底部显示“忘记密码 · 请联系老师”和未成年人使用提示。

界面要让不会阅读长文的儿童也能看懂，字段标签清楚，输入区大，主操作唯一。不要添加注册、第三方登录、广告或成人化插画。
```

### 身份选择页

```text
生成身份选择页，顶部使用浅紫到浅蓝的圆角欢迎卡片，包含标题“你是谁呀？”、辅助说明和小鹿吉祥物。

身份卡片依次为“我是小学生”“我是老师”“我是家长”。学生卡片使用紫色强调边框和“进入”操作；教师与家长卡片降低透明度，显示“本期暂不制作 / 暂未开放”，不可点击。页面底部提供“以学生身份进入”和“返回登录”。

每张身份卡包含彩色圆角图标、身份名称、简短功能说明和状态胶囊。不要生成教师端或家长端的后续页面。
```

### 学生首页

```text
生成 LUMI 学生首页，面向幼儿园大班至小学六年级。顶部展示小鹿头像、问候“早上好，陈小鹿”和连续学习 12 天的火焰徽章。

首屏使用深紫渐变冒险卡片作为视觉中心，标题“今天也要勇敢开口说英语！”，包含黄色“继续学习”按钮和小鹿吉祥物。下方展示今日进度 3/5、星星宝箱提示。

今日任务包括自然拼读、动物园口语、单词复习。每个任务卡包含彩色图标、标题、一行说明、预计时间、星星奖励和进入箭头，第一个任务显示“推荐先学”。底部放置浅紫蓝 AI 伙伴卡片，文案“讲故事、练口语，哪里不会就问哪里”。

底部导航为首页、学习、AI伙伴、作业、我的；首页为选中状态，AI伙伴按钮可稍微突出。保持一屏信息重点明确，不使用复杂图表。
```

### 学习页

```text
生成“学习乐园”页面。首屏展示正在学习的“自然拼读 · sh”，包括课程进度、发音符号、播放按钮和继续学习按钮。下方以两列卡片展示自然拼读、单词乐园、情景口语、趣味听力，再用纵向步骤展示今日学习路线。每个步骤明确标记完成、进行中或待解锁，避免课程目录过深。
```

### AI伙伴页

```text
生成“AI 英语伙伴”页面。顶部显示 Lumi 在线和儿童安全陪伴模式；中部使用小鹿卡片说明“可以说中文，也可以试试英语”。聊天区域区分 Lumi 与学生消息，英文回答下方提供简短中文解释和“听一听”按钮。底部提供三个快捷话题、文字输入、语音输入和发送按钮。不得出现成人话题、开放网络搜索或隐私信息诱导。
```

### 作业页

```text
生成“作业中心”页面。顶部显示今日待完成数量和本周正确率；使用“待完成、批改中、已完成”三个状态标签切换内容。作业卡包含作业类型图标、状态、标题、简短要求和唯一操作。待完成示例包括书面拍照作业、口语录音；批改中示例为小作文；已完成示例显示得分和订正数量。加入简短拍照提示，但不实现真实上传。
```

### 我的成长页

```text
生成“我的成长”页面。展示学生头像、学校班级、等级称号、连续学习、本周星星、词汇/口语/阅读/写作四项能力进度、本周学习计划、勋章和错题本入口。进度反馈鼓励为主，不展示公开排名，不把学生与具体同学比较，不使用焦虑或惩罚性文案。
```

## 6. 组件生成提示词

```text
建立可复用儿童教育组件库：PrimaryButton、SecondaryButton、TaskCard、RoleCard、ProgressCard、RewardBadge、StatusPill、BottomNavigation、LumiMascot、EmptyState、LoadingState、SuccessCelebration。

所有组件包含 default、hover、pressed、disabled、loading 状态。主按钮保持高对比；禁用状态不能只依赖颜色；任务完成使用绿色勾选和星星奖励；错误提示避免红色恐吓式表达，使用温和文案“再试一次，我们快成功啦”。
```

## 7. 交互与动效提示词

```text
为界面增加克制的儿童友好互动：按钮按下缩放至 0.98；吉祥物上下漂浮 4–6px；任务完成出现 0.8 秒星星庆祝；页面切换使用 180–240ms 淡入与轻微上移。所有动画不影响阅读和点击，禁止持续闪烁、强烈弹跳和大面积粒子效果，并提供减少动态效果适配。
```

## 8. 前端代码生成提示词

```text
使用 React + TypeScript 实现移动端优先的 LUMI 学生端。实现登录、身份选择、学生首页、学习、AI伙伴、作业和我的成长，并通过本地状态完成导航、作业筛选、AI演示对话和语音按钮反馈。不连接真实后端，不创建教师端或家长端业务页面。

使用语义化 HTML、CSS 变量和可复用组件。禁止把整个页面做成图片，禁止内联复杂 SVG，吉祥物可使用 CSS 图形或可替换图片槽位。支持 390×844 设计宽度，同时适配 320–768px；桌面端居中显示手机预览框。保证键盘焦点可见、按钮有 aria-label、文字对比度清楚、触控区域至少 48px，并支持 prefers-reduced-motion。
```

## 9. 负向提示词

```text
不要成人企业后台风；不要深黑科技风；不要霓虹色；不要玻璃拟态堆叠；不要大量渐变；不要复杂数据表格；不要长段落；不要小于 9px 的关键信息；不要用纯颜色区分状态；不要制作教师端、家长端或管理端；不要添加未确认的付费、排行榜、社交、广告、直播功能；不要让吉祥物遮挡按钮和文字；不要过度幼儿化到小学高年级拒绝使用。
```

## 10. 一次性总提示词

```text
请为 LUMI 儿童英语智能学习平台设计并实现学生端 UI。目标用户为幼儿园大班至小学六年级，风格可爱、温暖、鼓励、清爽，不能杂乱或过度低龄。以柔和紫色为品牌主色，天空蓝、薄荷绿、阳光黄和珊瑚粉为辅助色，配合圆角卡片、轻柔阴影、星星/云朵装饰和紫色小鹿 Lumi 吉祥物。

制作七个移动端界面：登录页、身份选择页、学生首页、学习、AI伙伴、作业、我的成长。登录页突出家长/教师协助；身份页只允许学生进入；首页包含今日任务；学习页包含课程和学习路线；AI伙伴包含安全对话演示；作业页包含三个状态筛选；成长页包含能力、计划、勋章与错题本。所有学生页面共享五栏底部导航。

使用 React + TypeScript 和语义化 CSS 实现，移动端优先，桌面端居中展示手机容器。建立统一设计变量和复用组件，提供 hover、pressed、disabled 状态，保证 48px 触控区域、清晰对比度、键盘焦点和减少动态效果适配。只使用演示数据，不连接后端，不扩展教师端、家长端和其他业务页面。
```

## 11. 验收清单

- 可按“登录 → 身份选择 → 学生首页”进入，并通过底部导航切换四个学生功能页。
- 学习页播放按钮、AI演示对话、作业状态筛选和成长页计划入口具备前端反馈。
- 教师和家长卡片视觉保留但不可进入。
- 390×844 下无横向滚动，320px 宽度仍可使用。
- 主操作在每个页面首屏清晰可见。
- 任务名称、时间、奖励和进度能快速辨认。
- 装饰不遮挡正文和按钮。
- 页面可爱但不过度幼儿化，适合小学高年级继续使用。
- 不包含后端、真实上传、真实AI调用和其他角色页面。
